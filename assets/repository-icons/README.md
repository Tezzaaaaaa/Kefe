# Repository icon language

KEFE keeps repository navigation visually identifiable without coupling the app to an icon package.

## Semantic mapping

| Repository identifier | Icon language | Meaning |
|---|---|---|
| `app/` | application / window | Frontend application |
| `core/` | CPU / engine | Analysis, runtime and rendering core |
| `effects/` | sparkle / motion | Lyric and visual effects |
| `export/` | download / output | Video export pipeline |
| `ui/` | sliders / controls | Editor interface |
| `assets/` | image / media | Static and branding assets |
| `fonts/` | typography | Production fonts |
| `vendor/` | package / dependency | Vendored third-party runtimes |
| `server/` | server / cloud | Node backend |
| `tests/` | checklist / verification | Automated tests |
| `scripts/` | terminal / automation | Repository tooling |
| `docs/` | book / documentation | Project documentation |
| `ifixai/` | shield / audit | Audit/security material |
| `.github/` | workflow / automation | CI/CD and repository automation |

These icons are documentation/navigation metadata only. They are not loaded by the application at runtime.

## Brand identifiers

- Primary wordmark: `kefe-logo`
- Dark-surface wordmark: `kefe-logo-light`
- Full lockup: `kefe-logo-full`
- Browser icon: `favicon`
- Primary playback control: `play-button`
- Secondary icon control: `icon-button`
- Brand red: `#EF3F38`

The brand identifiers above should be preferred over ad-hoc names when documenting or referring to KEFE visual assets.
