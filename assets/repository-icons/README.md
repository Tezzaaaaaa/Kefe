# Repository icon language

KEFE keeps repository navigation visually identifiable without coupling the app to an icon package.

The canonical semantic mapping is:

- `app/` — application / window
- `core/` — CPU / engine
- `effects/` — sparkle / motion
- `export/` — download / output
- `ui/` — sliders / controls
- `assets/` — image / media
- `fonts/` — typography
- `vendor/` — package / dependency
- `server/` — server / cloud
- `tests/` — checklist / verification
- `scripts/` — terminal / automation
- `docs/` — book / documentation
- `ifixai/` — shield / audit
- `.github/` — workflow / automation

These icons are documentation/navigation metadata only. They are not loaded by the application at runtime.
